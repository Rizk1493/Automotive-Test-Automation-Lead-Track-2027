## Skill Validation Rule

A skill becomes GREEN only when all four are true:

1. I understand it.
2. I can perform it without step-by-step help.
3. I can apply it to an automotive scenario.
4. I can explain it clearly in an interview.

Self-rating alone does not make a skill GREEN.
